This repository contains the Python and IPython Notebook source files and datasets accompanying the book **Learning scikit-learn: Machine Learning in Python**.

The project explores practical machine learning techniques using Python and scikit-learn, including classification, regression, clustering, image recognition, text analysis and model selection.

The original book was written by Raúl Garreta and Guillermo Moncecchi. Diego Garat was added as an author for the planned second edition.

## 🚀 Getting Started

Follow these steps to set up the project locally.

### Step 1: Clone the repository

```bash
git clone https://github.com/gmonce/scikit-learn-book.git
```

### Step 2: Navigate to the project directory

```bash
cd scikit-learn-book
```

### Step 3: Create a virtual environment

```bash
python3 -m venv .venv
```

### Step 4: Activate the environment

**macOS / Linux:**

```bash
source .venv/bin/activate
```

### Step 5: Install the required libraries

```bash
pip install numpy scipy pandas matplotlib scikit-learn jupyter
```

### Step 6: Launch Jupyter Notebook

```bash
jupyter notebook
```

Once Jupyter opens in your browser, select the notebook corresponding to the chapter you want to explore.

> **Compatibility note:** These notebooks originate from an earlier edition of the book. Some examples may require code changes or older library versions to work with modern Python and scikit-learn releases.
